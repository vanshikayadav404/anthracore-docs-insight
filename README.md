# AnthraCore Insights

Build a web app called "AnthraCore" — an AI-powered document intelligence

platform for CMPDI/Coal India Ltd geological & mining reports.

Design language: dark navy background (#0B1F3A style), white content cards,

amber/orange accent color for highlights and CTAs (coal + energy feel),

clean sans-serif typography, subtle shadows, no gradients. Professional

government/enterprise product feel, not playful. Include a top nav with

"AnthraCore" logo/wordmark and a sidebar with: Dashboard, Upload & Process,

Ask AnthraCore, Parliamentary Reports, Insights.

This is a CLICKABLE DEMO PROTOTYPE with simulated data — no real backend,

no real file processing, no real AI calls. All "AI" behavior should be

hardcoded responses shown after a realistic fake loading delay (2-3 sec

spinner with text like "Extracting text...", "Cross-validating against

historical records...", "Generating grounded response..."). Build the

Dashboard screen first (see next prompt).
